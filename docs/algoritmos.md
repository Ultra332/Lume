# Algoritmos com Lume

Algoritmo é uma sequência finita e explícita de passos para resolver um problema. Em Lume, comece identificando entradas, resultado esperado e casos-limite; depois traduza cada passo para variáveis, condições, repetições e funções.

## Progressão sugerida

1. **Sequência:** leia ou declare valores, calcule e mostre o resultado.
2. **Decisão:** use `se` para escolher entre caminhos.
3. **Contagem:** use `para` quando os limites são conhecidos.
4. **Repetição condicional:** use `enquanto` quando a parada depende do estado.
5. **Coleções:** percorra listas e acumule resultados.
6. **Decomposição:** transforme etapas com nomes claros em funções.

## Exemplos clássicos

- Média: some os elementos e divida por `tamanho(lista)`; considere a lista vazia.
- Maior valor: inicie com o primeiro elemento, depois compare os demais.
- Busca linear: percorra até encontrar o alvo e registre sua posição.

Versões executáveis estão em `exemplos/algoritmos`.

## Exercícios

1. Conte quantos números de uma lista são pares.
2. Inverta um texto usando `texto.tamanho` e `texto.caractere`.
3. Crie uma função que devolva o menor número de uma lista não vazia.
4. Verifique se um texto é palíndromo.
5. Calcule o fatorial de forma iterativa e recursiva.

Compare abordagens somente depois de tentar. Soluções comentadas ficam em [solucoes.md](solucoes.md); elas são referências, não a única resposta correta.
