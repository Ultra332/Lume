# Depois da Lume

Ao concluir os materiais, o estudante já pode reconhecer valores, estado, controle de fluxo, funções, escopo, coleções, módulos e testes. O passo seguinte depende do objetivo:

- Python ou JavaScript para automação e aplicações com ecossistemas amplos;
- C para estudar memória, representação e sistemas;
- uma linguagem funcional para explorar imutabilidade e composição;
- estruturas de dados, testes e análise de algoritmos independentemente da linguagem.

Compare conceitos, não apenas sintaxe: como cada linguagem representa ausência de valor, mutabilidade, módulos, erros e coleções? Reimplementar um pequeno projeto Lume em outra linguagem torna essas diferenças concretas.
