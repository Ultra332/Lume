# Funções

## O que vamos aprender

- reunir uma tarefa com um nome;
- receber parâmetros;
- devolver um resultado.

## Primeiro exemplo

```lume
funcao dobro(numero) {
    retorne numero * 2
}

escreva(dobro(6))
```

## O que aconteceu?

`dobro` descreve uma tarefa que pode ser usada muitas vezes. `numero` é o parâmetro: ele recebe 6 durante essa chamada. `retorne` envia 12 de volta ao ponto da chamada.

## Agora tente

Crie `somar(a, b)` e use a função com três pares de números.

## Dica

Uma função pode receber vários parâmetros separados por vírgula.

## Veja a execução

Use `lume --explicar funcoes.lume` para observar chamada, parâmetros e retorno.
