# Repetições

## O que vamos aprender

- repetir usando um intervalo;
- percorrer valores;
- reconhecer quando o laço termina.

## Primeiro exemplo

```lume
para numero de 1 ate 5 {
    escreva(numero)
}
```

## O que aconteceu?

O bloco executa cinco vezes. Em cada volta, `numero` recebe o próximo valor. Esse tipo de repetição também é chamado de laço.

`enquanto` é útil quando a quantidade de voltas depende de uma condição. `pare` encerra um laço e `continue` pula para a próxima volta.

## Agora tente

Mostre a tabuada do 5, de 1 até 10.

## Dica

Dentro do `para`, mostre `5 * numero`.

## Veja a execução

Use `lume --passo tabuada.lume`; pressione Enter para acompanhar cada acontecimento e `c` para continuar.
