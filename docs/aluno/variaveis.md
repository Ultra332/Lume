# Variáveis

## O que vamos aprender

- guardar valores com nomes;
- diferenciar texto de número;
- alterar uma variável.

## Primeiro exemplo

```lume
variavel nome = "Maria"
variavel pontos = 10
pontos = pontos + 5
escreva(nome)
escreva(pontos)
```

## O que aconteceu?

Uma variável é uma etiqueta para um valor. `nome` guarda texto porque o valor usa aspas. `pontos` guarda um número e depois passa de 10 para 15. O `=` coloca o resultado da direita na variável da esquerda.

Uma `constante` também dá nome a um valor, mas não permite trocá-lo depois.

## Agora tente

Crie variáveis para seu nome, sua idade e seu assunto favorito. Mostre todas.

## Dica

Números não usam aspas. Para juntar texto e número, converta o número com `texto(idade)`.

## Veja a execução

Salve como `variaveis.lume` e execute `lume --explicar variaveis.lume`.
